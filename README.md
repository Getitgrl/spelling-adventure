
# Spelling Adventure

A kid-friendly spelling practice game built with Streamlit.

## Starter spelling list
- disconnect
- disobey
- nondairy
- nonremovable
- nonstick
- rearrange
- refreeze
- uncooked
- unidentified
- untangle

## Run it locally
1. Install Python 3.10+
2. Open a terminal in this folder
3. Run:
   `pip install -r requirements.txt`
4. Then run:
   `streamlit run app.py`

## Put it online free with Streamlit Community Cloud
1. Create a GitHub account if you do not already have one.
2. Create a new GitHub repository.
3. Upload `app.py` and `requirements.txt`.
4. Go to Streamlit Community Cloud.
5. Choose "Create app" and connect your GitHub repository.
6. Select `app.py` as the main file and deploy.

The parent setup screen lets you replace the spelling list every week without changing the code.
